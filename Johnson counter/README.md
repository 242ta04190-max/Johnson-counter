# 4-bit Johnson Counter using Verilog

## Overview

This project implements and simulates a **4-bit Johnson Counter** using Verilog HDL.

A Johnson counter, also known as a **twisted ring counter**, is a shift register in which the inverted output of the last flip-flop is connected back to the input of the first flip-flop.

For an N-bit Johnson counter, the counter produces **2N unique states**.

For a 4-bit Johnson counter:

```text
2 × 4 = 8 states
```

## Features

* 4-bit Johnson counter
* Clock-driven operation
* Asynchronous reset
* 8 unique states
* Verilog HDL implementation
* Testbench verification
* GTKWave simulation

## Johnson Counter Sequence

After reset, the counter starts at:

```text
0000
```

The sequence is:

```text
0000 → 1000 → 1100 → 1110
     → 1111 → 0111 → 0011 → 0001
     → 0000
```

## Inputs and Outputs

### Inputs

* `CLK` – Clock signal
* `RESET` – Reset signal

### Output

* `Q[3:0]` – 4-bit Johnson counter output

## Operation

When `RESET` is HIGH, the counter is initialized to:

```text
0000
```

When `RESET` is LOW, the counter shifts its bits on every rising edge of the clock.

The inverted least-significant bit is fed back into the most-significant bit.

The sequence is:

```text
0000 → 1000 → 1100 → 1110
→ 1111 → 0111 → 0011 → 0001
→ 0000
```

## Simulation

This project can be simulated using **Icarus Verilog** and **GTKWave**.

### Step 1: Compile

```bash
iverilog -o johnson_sim johnson_counter_4bit.v tb_johnson_counter_4bit.v
```

### Step 2: Run

```bash
vvp johnson_sim
```

The testbench generates:

```text
waveform.vcd
```

### Step 3: View Waveform

```bash
gtkwave waveform.vcd
```

Add these signals to GTKWave:

```text
CLK
RESET
Q
```

## Applications

Johnson counters are used in:

* Sequence generators
* Timing circuits
* Digital control systems
* Frequency division
* LED chaser circuits

## Advantages

* Produces 2N states using N flip-flops
* Simple decoding logic
* Easy to implement
* Useful for timing and sequencing
* Requires fewer decoding gates than some conventional counters
